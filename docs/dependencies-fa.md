# وابستگی‌های پروژه (Dependencies) 📚

جدول همه پکیج‌هایی که در `pubspec.yaml` تعریف شده‌اند: هر کدام چه کار می‌کند، چرا انتخاب شده و در کدام مرحله استفاده می‌شود.

> بسته: `com.englishteacher.app` — نسخه: `1.0.0+1`

## وابستگی‌های اصلی

| پکیج | چه کار می‌کند؟ | چرا این انتخاب؟ | مرحله استفاده |
|---|---|---|---|
| `provider` | مدیریت وضعیت (State Management)؛ داده‌ها را بین صفحه‌ها به اشتراک می‌گذارد | سبک، ساده و رسمی‌ترین راه پیشنهادی فلاتر؛ برای اپ آموزشی بدون پیچیدگی اضافی کافی است | ۱ (حساب‌ها و وضعیت ورود) و همه مراحل |
| `sqflite` | دیتابیس محلی SQLite روی گوشی | آفلاین، سریع، بدون نیاز به اینترنت؛ همه داده‌های کاربر روی خودش می‌ماند | ۱ (اسکیمای کامل دیتابیس) |
| `path` | ساخت مسیر فایل‌ها به شکل استاندارد هر سیستم‌عامل | همراه همیشگی `sqflite` برای آدرس فایل دیتابیس | ۱ |
| `path_provider` | پیدا کردن پوشه‌های استاندارد گوشی (مثل پوشه اسناد) | برای ذخیره فایل دیتابیس و فایل‌های کاربر در جای درست | ۱ |
| `cryptography` | رمزنگاری (AES و ...) | سبک و چندسکویی؛ برای رمز کردن کلید API معلم هوش مصنوعی در تنظیمات | ۱ (زیرساخت) و ۵ (کلید AI) |
| `google_fonts` | فونت‌های گوگل، از جمله **وزیرمتن** | بدون اینکه فایل فونت را داخل APK بگذاریم، فونت فارسی قشنگ داریم؛ حجم APK کم می‌ماند (زیر ۵۰ مگ) | ۱ (تم و ظاهر) |
| `shared_preferences` | ذخیره تنظیمات ساده (کلید-مقدار) | برای چیزهای کوچک مثل «تم روشن/تیره» یا «آخرین حساب واردشده»؛ ساده‌تر از دیتابیس | ۱ |
| `intl` | قالب‌بندی تاریخ، ساعت و اعداد | نمایش تاریخ فارسی و قالب‌بندی درست متن‌ها | ۱ و همه مراحل |
| `uuid` | ساخت شناسه یکتای تصادفی | برای شناسه حساب‌ها و رکوردهاست تا در همگام‌سازی ابری (مرحله ۷) تداخل پیش نیاید | ۱ (حساب‌ها) و ۷ |
| `http` | درخواست‌های HTTP | سبک و رسمی دارت؛ برای فراخوانی REST API جمینای (متن + استریمینگ SSE) | ۵ (معلم هوش مصنوعی) |
| `flutter_secure_storage` | ذخیرهٔ امن کلیدها (Android Keystore + AES-GCM) | کلید API هرگز نباید در SharedPreferences یا کد باشد؛ امن‌ترین راه استاندارد | ۵ (کلید Gemini) |
| `google_mlkit_text_recognition` | تشخیص متن دست‌نویس/چاپی آفلاین (OCR) روی گوشی | آفلاین و رایگان؛ مدل‌ها موقع اولین استفاده دانلود می‌شوند (حجم APK کم می‌ماند) | ۲ (اسکن) |
| `google_mlkit_translation` | ترجمهٔ آفلاین انگلیسی → فارسی روی گوشی | بدون اینترنت کار می‌کند؛ مدل‌ها موقع اولین استفاده دانلود می‌شوند | ۳ (ترجمه) |
| `flutter_lints` | قوانین استاندارد تحلیل کد | کد تمیز و یکدست؛ ورک‌فلو `flutter analyze` با همین قوانین چک می‌کند | ابزار توسعه (dev) |
| `firebase_core` | هستهٔ Firebase | پایهٔ همهٔ سرویس‌های Firebase؛ بدون آن هیچ‌کدام کار نمی‌کنند | ۷ (همگام‌سازی ابری) |

| `firebase_storage` | فضای ذخیرهٔ فایل Firebase | (زیرساخت آماده برای فایل‌های آینده؛ فعلاً فقط متن همگام می‌شود) | ۷ |
| `connectivity_plus` | تشخیص وضعیت اینترنت | همگام‌سازی خودکار وقتی اینترنت برمی‌گردد | ۷ |
| `pdf` | ساخت فایل PDF | خروجی PDF فارسی راست‌به‌چپ با فونت وزیرمتن (دانلود اولین‌بار) | ۷ (خروجی PDF) |
| `printing` | فونت PDF از گوگل | دانلود فونت وزیرمتن برای PDF (PdfGoogleFonts؛ اولین‌بار به اینترنت نیاز دارد) | ۷ (خروجی PDF) |
| `share_plus` | شیت اشتراک‌گذاری سیستم | ارسال فایل PDF/JSON به واتساپ، ایتا، ایمیل و... | ۷ (خروجی) |

## نکته‌ها

- **چرا `google_fonts` به‌جای فونت داخل اپ؟** فایل فونت وزیرمتن چند مگابایت است؛ با `google_fonts` فونت موقع اجرا دانلود و کش می‌شود و APK سبک می‌ماند. (نکته آفلاین: اولین اجرا اینترنت لازم دارد — جزئیات در [build-errors-fa.md](build-errors-fa.md))
- **چرا `cryptography` به‌جای پکیج‌های سنگین‌تر؟** فقط همان چیزی را می‌دهد که لازم داریم (رمزنگاری کلید)، بدون وابستگی اضافه.
- در مرحله ۷ (همگام‌سازی ابری) این‌ها اضافه شدند: `firebase_core`، `firebase_auth`، `cloud_firestore`، `firebase_storage`، `connectivity_plus`، `pdf`، `printing`، `share_plus`.
- **رفع تداخل نسخه‌های ML Kit (مرحله ۶):** `google_mlkit_text_recognition: ^0.13.1` به `google_mlkit_commons: ^0.8.1` نیاز داشت ولی `google_mlkit_translation: ^0.13.0` به `^0.11.0` — این دو بازه هم‌پوشانی نداشتند و `flutter pub get` در حل نسخه شکست می‌خورد. با ارتقا به `google_mlkit_text_recognition: ^0.15.1` (که به `google_mlkit_commons: ^0.11.0` نیاز دارد) تداخل رفع شد؛ API دارتِ استفاده‌شده (`TextRecognizer`، `TextRecognitionScript.latin`، `close()`) بین این نسخه‌ها تغییری نکرده است.
