# راهنمای گرفتن کلید Google AI Studio

کلید API برای «معلم هوش مصنوعی» لازم است (چت، تحلیل خودکار قواعد، ترجمهٔ آنلاین و OCR آنلاین). گرفتنش رایگان است و حدود ۲ دقیقه طول می‌کشد.

## قدم‌ها

1. وارد [Google AI Studio](https://aistudio.google.com) شو (با حساب گوگل).
2. از منوی سمت چپ روی **Get API Key** (دریافت کلید API) بزن.
3. روی **Create API Key** بزن و یک پروژهٔ جدید بساز (یا پروژهٔ موجود را انتخاب کن).
4. کلیدی که نمایش داده می‌شود (شروع می‌شود با `AIza`) را کپی کن.
5. در اپ، به **تنظیمات → کلید Google AI Studio** برو، کلید را بچسبان و **ذخیرهٔ کلید** را بزن.

## نکات مهم

- **کلید را به هیچ‌کس نده** و در چت یا ایمیل نفرست؛ هرکس کلید تو را داشته باشد می‌تواند از سهمیه‌ات استفاده کند.
- اگر فکر می‌کنی کلیدت لو رفته، در همان صفحهٔ AI Studio روی **Delete** بزن و یک کلید تازه بساز، بعد در اپ جایگزینش کن.
- کلید فقط در **حافظهٔ امن گوشی** (Android Keystore) ذخیره می‌شود و هیچ‌وقت در کد اپ یا هیچ سروری ذخیره نمی‌شود.
- سهمیهٔ رایگان محدود است؛ اگر پیام «سهمیهٔ امروز تمام شده» دیدی، چند ساعت بعد دوباره تلاش کن.
- اگر به اینترنت آزاد (بدون فیلتر) دسترسی نداری، ممکن است برای اتصال به گوگل به VPN نیاز داشته باشی.
