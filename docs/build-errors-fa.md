# خطاهای پرتکرار بیلد و راه‌حل 🛠️

رایج‌ترین خطاهایی که موقع `flutter build apk` یا در GitHub Actions ممکن است ببینی، به‌همراه راه‌حل.

---

## ۱. ناسازگاری نسخه Gradle / JDK ☕

**نشانه:** خطاهایی مثل `Unsupported class file major version` یا `Could not determine java version`.

**علت:** نسخه جاوای نصب‌شده با نسخه Gradle پروژه نمی‌خواند.

**راه‌حل:**
- پروژه با **Java 17** ساخته می‌شود (ورک‌فلو `build-apk.yml` همین را نصب می‌کند).
- اگر لوکال بیلد می‌گیری: `java -version` باید ۱۷ باشد. اگر چند جاوا داری، `JAVA_HOME` را روی JDK 17 بگذار.
- نسخه Gradle و Android Gradle Plugin را در `android/gradle/wrapper/gradle-wrapper.properties` و `android/settings.gradle` دست نزن مگر اینکه بدانی چه می‌کنی.

## ۲. خطای `flutter pub get` (پروکسی / اینترنت) 🌐

**نشانه:** `Got socket error` یا گیر کردن روی `Resolving dependencies...`.

**علت:** قطعی اینترنت یا فیلترینگ؛ گاهی هم کش خراب.

**راه‌حل:**
```bash
flutter pub cache clean
flutter pub get
```
- با VPN امتحان کن.
- در GitHub Actions این مشکل معمولاً نیست (اینترنت آزاد دارد).

## ۳. تداخل minSdk ⛔

**نشانه:** `uses-sdk:minSdkVersion XX cannot be smaller than version YY declared in library`.

**علت:** یکی از پکیج‌ها (مثلاً `sqflite` در گوشی‌های خیلی قدیمی) به minSdk بالاتر نیاز دارد.

**راه‌حل:** در `android/app/build.gradle` مقدار `minSdk` را به عددی که خطا گفته بالا ببر (مثلاً ۲۱ یا ۲۳). توجه: بالا بردن minSdk یعنی گوشی‌های خیلی قدیمی‌تر دیگر پشتیبانی نمی‌شوند.

## ۴. خطای امضا: INSTALL_FAILED_UPDATE_INCOMPATIBLE 🔑

**نشانه:** موقع نصب نسخه جدید: «App not installed» و در لاگ `INSTALL_FAILED_UPDATE_INCOMPATIBLE`.

**علت:** نسخه قبلی با کلید دیگری امضا شده (مثلاً قبلی debug بوده و جدیدی release، یا keystore عوض شده).

**راه‌حل:**
1. نسخه قبلی را کامل **Uninstall** کن، بعد نسخه جدید را نصب کن (داده‌های قبلی پاک می‌شود!).
2. **پیشگیری:** از اول با همان keystore ثابت امضا کن — راهنمای کامل در [build-apk-fa.md](build-apk-fa.md) بخش «ج».

## ۵. خطای shrink / R8: کلاس گم‌شده 🗜️

**نشانه:** موقع بیلد release: `Missing classes detected by R8` یا کرش بعد از نصب نسخه release در حالی که debug سالم است.

**علت:** کوچک‌ساز (R8) کدی را که با reflection صدا زده می‌شود حذف کرده.

**راه‌حل:**
- اول مطمئن شو مشکل از shrink است: یک‌بار بدون `--shrink` بیلد بگیر؛ اگر درست شد، مشکل همین است.
- برای پکیج‌هایی مثل `sqflite` معمولاً نیازی به قانون اضافه نیست؛ اگر پکیج جدیدی اضافه کردی و این خطا آمد، فایل `android/app/proguard-rules.pro` را با keep-rule همان پکیج به‌روز کن.

## ۶. `google_fonts` در اولین اجرای آفلاین 🔤

**نشانه:** اولین بار که بدون اینترنت برنامه را باز می‌کنی، فونت فارسی اعمال نمی‌شود و فونت پیش‌فرض زشت دیده می‌شود.

**علت:** `google_fonts` فونت را در اولین اجرا دانلود می‌کند و کش می‌کند.

**راه‌حل:** این خطا نیست، رفتار طبیعی است — کافی است **یک‌بار با اینترنت** برنامه را باز کنی تا فونت کش شود؛ بعد از آن آفلاین هم درست است.

## ۷. `sqflite` روی گوشی‌های خیلی قدیمی 💾

**نشانه:** کرش موقع باز کردن دیتابیس در اندرویدهای خیلی قدیمی (زیر ۵).

**علت:** نسخه‌های قدیمی اندروید SQLite قدیمی دارند.

**راه‌حل:** با `minSdk` فعلی پروژه (که گوشی‌های مدرن را پوشش می‌دهد) این مشکل عملاً پیش نمی‌آید. اگر روزی minSdk را خیلی پایین آوردی، باید نسخه SQLite را هم در نظر بگیری.

## ۸. کدام APK را نصب کنم؟ (split-per-abi) 📦

**نشانه:** سه فایل APK ساخته شده و نمی‌دانی کدام را نصب کنی.

**راه‌حل:**
- **`app-arm64-v8a-release.apk`** ← گوشی‌های امروزی (از ~۲۰۱۷ به بعد) — اول همین را امتحان کن.
- **`app-armeabi-v7a-release.apk`** ← گوشی‌های قدیمی ۳۲ بیتی.
- **`app-x86_64-release.apk`** ← فقط شبیه‌ساز کامپیوتر.
